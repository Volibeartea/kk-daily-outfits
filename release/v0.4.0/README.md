# KK Daily Outfits

Automatically change each character's bra and panties every in-game day, while keeping other clothing and accessories unchanged.

## Quick start

1. Load your story-mode save.
2. Press **F1** → **Plugin settings** → **KK Daily Outfits**.
3. Under **Character wardrobes**, select a folder for each character you want to enable. Characters are **Disabled** by default.
4. Advance to the next day.

Put coordinate card PNGs in `UserData/DailyOutfits/DefaultCloset`, or create your own folders inside `DailyOutfits`. Multiple characters can share the same folder. Use **Refresh folders** under **OutfitFolder** after adding folders.

- **Disabled** stops daily outfit changes for that character.
- **NoRepeatDays** sets how many days an outfit cannot repeat. The default is **1**; **0** disables the limit. If there are too few outfits, the least recently worn one is used.
- **Show wardrobe status** displays the last applied outfit and cooldown status.
- **ShowStoryCharacters** reveals story characters in the settings list.

Save the game before quitting to keep each character's wear history.
